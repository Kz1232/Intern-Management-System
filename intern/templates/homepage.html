Intern Management REST API

Django REST Framework backend with JWT authentication, task management and attendance tracking.

Swagger UI ReDoc

Core Features

🔐

JWT Authentication

Access tokens, refresh tokens and secure logout using token blacklisting.

📋

Task Management

Supervisors can create, update, assign, delete and restore tasks.

📅

Attendance Tracking

Interns can mark attendance once per day with duplicate protection.

Tech Stack

  • Python + Django
  • Django REST Framework
  • SimpleJWT Authentication
  • drf_yasg (Swagger/ReDoc)
  • django-filter
  • SQLite Database

Authentication Endpoints

POST /app/user_register/
POST /app/sign_in/
POST /app/sign_out/
POST /api/token/refresh/
Example Login Request
{
    "username":"alice",
    "password":"pass1234"
}

Attendance API

POST /app/mark_attendence/

Marks attendance for the authenticated user. One attendance entry is allowed per day.

Task Endpoints

GET /app/tasks/
POST /app/tasks/
GET /app/tasks/{id}/
PUT /app/tasks/{id}/
PATCH /app/tasks/{id}/
DELETE /app/tasks/{id}/
POST /app/tasks/{id}/complete/
PATCH /app/tasks/{id}/soft_delete/
POST /app/tasks/{id}/restore/
Filtering Examples
GET /app/tasks/?assigned_to__username=alice
GET /app/tasks/?status=COMP
GET /app/tasks/?search=report
GET /app/tasks/?ordering=-created_at

Roles & Permissions

INTERN

  • Sign in
  • Mark attendance
  • View tasks
  • Complete assigned tasks

SUPERVISOR

  • Create tasks
  • Update tasks
  • Delete tasks
  • Restore tasks
  • Manage interns
